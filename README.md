# Red de Autos · Marketplace

Marketplace de autos 0km y usados para agencias multimarca y concesionarios oficiales.

- Vite + Tailwind CSS 4 + Swiper + íconos Lucide
- `npm install` y `npm run dev` para trabajar en local
- Cada push a `main` se publica solo en GitHub Pages (Settings → Pages → Source: GitHub Actions)

Estado: primera mitad de la home (header, menú lateral, hero, buscador, carrocerías, por qué elegirnos, destacados).
Las fotos son de ejemplo (Unsplash) hasta conectar el stock real.
