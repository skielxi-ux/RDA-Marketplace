Publicar vehículos

Cargá todo tu stock de una vez: completá la plantilla de Excel, arrastrá la carpeta de fotos (hasta 7 por auto), revisá y publicá.

Ingresá con tu agencia

La carga de autos es para agencias y concesionarios aprobados.

  1. 1

    Descargá la plantilla

    Una fila por auto, con un Código distinto para cada uno (A001, A002…). Las listas desplegables evitan errores de tipeo.

    Descargar plantilla
  2. 2

    Subí el Excel

    Si un código ya está publicado, ese auto se actualiza (no se duplica).

  3. 3

    Arrastrá las fotos

    Una carpeta por auto con el código como nombre (A001/) o fotos que empiecen con el código (A001-1.jpg). Máximo 7 por auto.

    Arrastrá la carpeta de fotos acá
